# 🚰 Classificação de Consumo de Água

🐍 Python
💻 Visual Studio Code
🐙 GitHub

Sistema em Python para classificação de consumo mensal de água ($m^3$) de acordo com o tipo de imóvel e regras de negócio específicas.

## ⚙️ Regras de Classificação
- **Comercial:** Exibe tarifa corporativa independente do consumo.
- **Apartamento ($< 10\text{ m}^3$):** Consumo econômico.
- **Apartamento ou Casa ($\le 25\text{ m}^3$):** Consumo moderado.
- **Outros casos:** Alerta de consumo excessivo.
